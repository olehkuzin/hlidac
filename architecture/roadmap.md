## Demo script (about 4 minutes)

1. **Problem:** side effects show up between visits. Monitoring helps, but naive alerts flood nurses (1 in 3 surveys alerted in PRO-TECT), and digital tools often exclude patients with disabilities.
2. **Scenario 1, mild, with VoiceOver on:** mild nausea → an approved, plain-language advice card with its source; no nurse task.
3. **Scenario 3, ambiguous, by text** (by voice only if WP17 gets done, D43): "Dnes jsem zvracela a je mi špatně od žaludku." → the red-flag screen first (fever, chills, unwell, blood in stool, each denial confirmed with a button: a missing red-flag answer never counts as "no problem") → then only what the text left open, with large buttons: "Kolik dnes jíte a pijete?" (answer "trochu méně"), "Kolikrát … zvracení?" (answer "3 až 5krát"), diarrhoea → **routine review** ("Hlášení si prohlédne zdravotní sestra"; nurse: one amber UKONS rating, review within 24 h; provisional Nausea ≥ 2, Vomiting ≥ 1). Checked on the in-memory store, Sat 17 Oct. Don't use "skoro nic nepila": UKONS rates "No significant intake" red, so the honest answer makes it urgent (seen in the IRIS run).
4. **Scenario 2, concerning, at 200 % text:** day 10 after the dose recorded in the hospital data, 38.4 °C and chills → the urgent screen at once → the alert in the clinician app **and** the demo mailbox. The nurse confirms the provisional grade; nobody acknowledges; advance the clock → fallback.
5. **IRIS portal:**
   - the Visual Trace of scenario 2's outbox rows: FHIR write-back, then the nurse's email;
   - the `QuestionnaireResponse` next to the hospital's own record, the CTCAE grade `Observation` going `preliminary` → `final`, `Task`, `Provenance`;
   - the SQL tables: the replayable assessment with its versions, and the audit row with exactly what the model saw.
6. **Security, proven:**
   - records never left IRIS; the model saw only the pseudonymised message (shown from the audit); one setting switches extraction to a local model (voice stays on the laptop, if WP17 is shown);
   - the access-control, CSRF and login tests (no header tests: WP31 dropped, D43);
   - the audit entry for every view.
7. **Quality:** the test suite (rules, red flags, uncertainty never lowers urgency) and the WCAG 2.2 AA checks; evaluation numbers (zero missed urgent cases, grade agreement, alert rate against a naive rule) only if WP21 gets done (D43).
